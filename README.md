# 🌧️ Ambience

Mix rain, noise, ocean waves, campfire and more for focus or sleep, then save your soundscape as an audio file.

**▶ Use it here: [https://drew-traldi.github.io/ambience-the-right-way/](https://drew-traldi.github.io/ambience-the-right-way/)**

- Free, no sign-up, no ads
- Runs entirely in your browser. Nothing you enter is sent to a server.
- Works on desktop and mobile

## Run it locally

It's a single HTML file. Download `index.html` and open it in any modern browser.
